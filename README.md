# Vektor Prima Studio — Enterprise Systems & Digital Architecture

Original interactive enterprise IT architecture showcase built with React 19, TypeScript, Tailwind CSS v4, GSAP ScrollTrigger, and Lenis.

## Core Modules

- **3D Isometric Topology Canvas**: Real-time interactive node mesh with packet telemetry routing and mouse-driven perspective rotation.
- **Enterprise Capacity & ROI Simulator**: Interactive infrastructure calculator estimating throughput, latency, and squad allocation across SLA tiers.
- **Architecture Blueprint Explorer**: Multi-tabbed technical schematic with live configuration inspection.
- **Centralized Design Tokens & Bilingual i18n**: Full Light/Dark theme token engine (`src/styles/tokens.css`) and Bahasa Indonesia / English localization (`src/locales/`).
